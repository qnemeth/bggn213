K-means clustering

The main function in “base R” for K-means clustering is called kmeans(). The input for this function can just be your data. It will calculate a distance matrix and try to categorize your data into a specified number (K) of groups.

The rnorm() function has only one required input, which is the number of outputs n that you want to be randomly drawn from a normal distribution. You can also optionally input the standard deviation sd and/or the mean.

Hierarchical Clustering

There are two ways you can do hierarchical clustering: bottom-up and top-down. Bottom-up is generally the default/main one.

The benefits of this method are that it allows us to use measures of similarity other than euclidean distance, and that it does not require us to input a set number of groups.

The main function for hierarchical clustering in base R is called hclust().

This function does not take our “raw” data directly, but rather you must provide it with a distance matrix. We can use the dist() function to create a euclidean distance matrix containing all the pairwise distances between points. The matrix given by dist() can then be used for the input of hclust().

d <- dist(z)
hc <- hclust(d)
hc

Call:
hclust(d = d)

Cluster method   : complete 
Distance         : euclidean 
Number of objects: 60

Plotting hc with base R will give us a dendrogram:

plot(hc)
abline(h = 8, col = "red")

Our data is separated into two main groups– we can figure this out by looking for the “biggest goal” or largest distance between branches/crossbars. Looking at the “biggest goal” (which we’ve separated out with a red line), there are two main branches. The first 30 numbers are all on one side/stemming from one branch of the plot, and the last 30 are on the other. This aligns with what we know about our data.

Like we did with the abline() on our plot, we can “cut” our tree at a given height (h) or number of branches (k) to yield groupings (i.e. clusters). In R we do this with the cutree() function.

cutree(hc, h = 8)

Background: Principle Component Analysis

Principal component analysis (PCA) projects features onto principal components. Principal components (PCs) are lines through the data. The goal is to reduce the number of things that you have to look at; i.e., PCA aims to reduce the features dimensionality while only losing a small amount of information. You are trying to visualize the variance (spread) of the data.

Note: it’s principal, not principle.

Principal components are new low dimensional axes (or surfaces) closest to the observations. Basically, they are lines of best fit.

The data have maximum variance among the first PC. The next PC will try to capture the maximum amount of variance remaining.

Other than visualizing groupings, PCA can also be really useful to identify outliers.
