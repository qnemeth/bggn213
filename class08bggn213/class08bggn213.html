Examine the input data using head(wisc.df, 4).

Features/variables described in the data:

  • radius: mean of distances from nucleus center to points on the perimeter
  • texture: a measure of nucleus roughness taken from the standard deviation of gray-scale values
  • perimeter: total boundary length of the nucleus, area: total area of the nucleus
  • smoothness: local variation in radius lengths, i.e. how “bumpy” the edge is
  • compactness: measures how circular vs. irregular the shape is
  • concavity: how deeply indented, and symmetry: how symmetric the nucleus is.
  • (___)_se: variability for each measurement
  • (___)_worst: most extreme/largest value for each measurement
  • diagnosis: pathologist’s expert evaluation of the biopsy sample (benign or malignant)

Principal Component Analysis (PCA)

Reminder: the main function in base R for PCA is prcomp().

Sometimes you have columns in your data that are on very different scales. For example, you might have one column with values in the hundreds, and another with binary values (1 & 0).

Since PCA checks for axes of maximum variance, it is going to find more variance in variables with larger scales. We want to make sure that our PCA doesn’t assign false significance to a certain variable, or ignore the contribution of another variable.

In our prcomp() function, we can use the argument scale = TRUE to scale our data.

wisc.pr <- prcomp(wisc.data, scale = TRUE)

Visualizing Our Results

PCA compresses a lot of data into something that captures the essence of the original data. It takes a large dataset with lots of dimensions and condenses it into something we can look at.

We can score data-points based on how much they influence a particular PC. For example, we can get a numerical approximation of how much a certain patient contributed to PC1.

These scores are all in wisc.pr$x, which we can plot in a “score plot”.

Call ggplot with library():

library(ggplot2)

Plot wisc.pr$x as a scatter-plot. We can colour the plot by diagnosis to check our work.

ggplot(wisc.pr$x) + 
  aes(PC1, PC2, col = diagnosis) +
  geom_point()

We can see a clear separation of benign & malignant diagnoses. The two clusters of patients are immediately apparent.

Variance Explained

Calculate the variance of each principal component by squaring the sdev component of wisc.pr (i.e. wisc.pr$sdev^2). Save the result as an object called pr.var.

pr.var <- (wisc.pr$sdev^2)
head(pr.var)
[1] 13.281608  5.691355  2.817949  1.980640  1.648731  1.207357

Calculate the variance explained by each principal component by dividing by the total variance explained of all principal components. Assign this to a variable called pve and create a plot of variance explained for each principal component.

pve <- pr.var/(sum(pr.var))
plot(c(1,pve), xlab = "Principal Component", 
     ylab = "Proportion of Variance Explained", 
     ylim = c(0, 1), type = "o")

Alternative plot:

barplot(pve, ylab = "Percent of Variance Explained",
     names.arg=paste0("PC",1:length(pve)), las=2, axes = FALSE)
axis(2, at=pve, labels=round(pve,2)*100 )

Clustering on PCA Results

Now we are going to combine PCA and hierarchical clustering. We will cluster on the PC scores instead of the original 30 features. Since PCA focuses on the directions of greatest variance, this can help give the clustering algorithm a cleaner signal to work with.

d <- dist(wisc.pr$x[,1:7])
wisc.pr.hclust <-hclust(d, method = "ward.D2")
plot(wisc.pr.hclust, labels = F)
abline(h = 60, col = "red", lty = 2)
wisc.pr.hclust.clusters <- cutree(wisc.pr.hclust, k = 2)

Q13. How well does the newly created hclust model with two clusters separate out the two “M” and “B” diagnoses?

We can get a “cross-table” by using table() to look at both vectors:

table(diagnosis, wisc.pr.hclust.clusters)
         wisc.pr.hclust.clusters
diagnosis   1   2
        B  28 329
        M 188  24

Stats:

  • True positives: 188
  • False positives: 28
  • True negatives: 329
  • False negatives: 24

Formulas:

  • Sensitivity: TP/(TP+FN)
  • Specificity: TN/(TN+FP)

For this model:

  • Sensitivity: 188/(188 + 24) = 88%
  • Specificity: 329/(329 + 28) = 92%

It separates out the actual diagnoses fairly well, but definitely not perfectly.

Q14. How well do the hierarchical clustering models you created in the previous sections (i.e. without first doing PCA) do in terms of separating the diagnoses? Again, use the table() function to compare the output of each model (wisc.hclust.clusters and wisc.pr.hclust.clusters) with the vector containing the actual diagnoses.

Compare the best hclust result with the actual diagnoses:

table(diagnosis, cut.ward)
         cut.ward
diagnosis   1   2
        B  20 337
        M 164  48

Stats:

  • True positives: 164
  • False positives: 20
  • True negatives: 337
  • False negatives: 48

For this model:

  • Sensitivity: 164/(164 + 48) = 77%
  • Specificity: 337/(337 + 20) = 94%

The model with hclust alone has slightly higher specificity but much lower sensitivity than the PCA + hclust model. The hclust model is much more likely to return false negatives, i.e., tell sick patients that they’re okay, than the PC + hclust model.

Therefore, to answer Q14, the hierarchical clustering model isn’t completely terrible, but in a context where false negatives can cause delayed care and seriously affect patient health outcomes, it should not be used in place of clustering on PCA.
