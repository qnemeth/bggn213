Creating Functions in R

Author

Quinn Nemeth

Background

All functions in R have at least three things:

  • A name: we pick this and use it to call the function
  • Input arguments: we argue with a function to get it to do what we want; these can be one or more comma-separated inputs
  • The body: the lines of R code that do the work of the function

First Function

Our code should be formatted as function_name <- function() {arguments}. Let’s write a function to add some numbers.

add <- function(x, y) {
  x + y
}

Let’s test it out:

add(1,100)
[1] 101
#You could write it as add(x = 1, y =100), but R already knows that the first value is x and the second is y due to your arguments.
add(c(1,2,10), 100)
[1] 101 102 110

Let’s give our function a default. Function arguments can be required or optional. Right now, both our x argument and our y argument are required, because they have no fallback value to use if the user does not supply one. However, we can change our function to have a default that R can use if there is no y input, making the y argument optional.

add <- function(x, y = 0) {
  x + y
}
add(100)
[1] 100

What if we wanted to run our add() function on three inputs? This function currently only has two input arguments, so it would return an error. Therefore, we need to add a third argument to the function.

add <- function(x, y = 0, z) {
  x + y 
}
add(1,100,10)
[1] 101

It doesn’t return an error, but the 10 still isn’t added. This is because you need to add z to your function’s body, too. However, this also means that now, you can no longer add only two inputs, since z is required. So, make sure to change z to an optional argument.

add <- function(x, y = 0, z = 0) {
  x + y + z
}
add(1,100,10)
[1] 111

R has the ability to take any number of inputs that you don’t have to spell out like our x, y, and z by using ..., which is called a “dots” or “ellipses” input argument.

A function will automatically return the last thing computed:

add_silly <- function(x, y = 0, z = 0) {
  ans <- x + y + z
  x
}
add_silly(1, 100)
[1] 1

So, sometimes you will need to add a return value. By using return(), you can explicitly output/return a value from a function.

add_silly <- function(x, y = 0, z = 0) {
  ans <- x + y + z
  x
  return(ans)
}
add_silly(1, 100)
[1] 101

DNA Sequence Generator

Now, we’re going to write a function that creates random nucleotide sequences of a user-specified length. This could be useful for creating control sequences for comparison.

A useful function to start with is the base R sample() function.

Note: by using ?functionname you can call up the help function, which gives you information about what a particular function does.

The sample() function has two required input arguments:

  • x: what group of elements you want the function to choose from
  • size: how many items you want it to choose.
sample(x = 1:10, size = 5)
[1] 9 2 8 3 4

Now, let’s use this function to make a random di-nucleotide sequence:

sample(x = c("A", "T", "C", "G"), size = 2)
[1] "A" "C"

If you try to set a size of 5, you get an error, because it can’t take a sample larger than the population. I.e., R won’t draw the same item multiple times. So, you can use replace = TRUE to allow duplicate characters.

sample(x = c("A", "T", "C", "G"), size = 5, replace = TRUE)
[1] "G" "C" "C" "A" "C"

Now, we can make this working piece of code into a function. We want to make the sequence length an optional input. So, we can set seqlength as an input argument that’s equal to a default value. Then, we want to set size equal to seqlength within the body of our function.

generate_dna <- function(seqlength = 25) {
    sample(c("A", "T", "C", "G"), size = seqlength, replace = TRUE)
}
generate_dna()
 [1] "C" "T" "A" "C" "A" "C" "A" "G" "C" "A" "C" "C" "C" "T" "T" "T" "C" "A" "C"
[20] "A" "A" "T" "C" "G" "A"
generate_dna(6)
[1] "A" "G" "G" "G" "G" "G"

We can also set a particular seqlength as a vector.

x <- generate_dna(6)
x
[1] "T" "G" "G" "A" "A" "A"

Optional Format Switch

Right now, our function returns sequences like this: "G" "G" "A" "G" "A" "T", i.e., as a multi-element character vector with one nucleotide per element of the vector.

We may want it to look like this instead: "GGAGAT".

A base R function that might help us with this is paste(). By using the help function (?paste), we can find out that paste() converts its arguments to character strings. Within the function, collapse = allows us to indicate what should be in between each pair of characters in the string. By writing collapse = "", we tell R that nothing should be separating the characters.

paste(x, collapse = "")
[1] "TGGAAA"

Let’s incorporate this into our generate_dna function.

generate_dna <- function(seqlength = 25) {
    n <- sample(c("A", "T", "C", "G"), size = seqlength, replace = TRUE)
    paste(n, collapse = "")
}
generate_dna()
[1] "GAATACCAGGGGTAGATGCTTGGAA"

Now, we want to make it so that the user can choose the format. For this, we can use a TRUE/FALSE input argument.

generate_dna <- function(seqlength = 25, fasta = TRUE) {
    n <- sample(c("A", "T", "C", "G"), size = seqlength, replace = TRUE)
    cat("Hello")
    if(fasta) {
      cat("Goodbye")
      n <- paste(n, collapse = "")
    }
    return(n)
}
#You can save a specific output by assigning it to a vector.
x <- generate_dna(6, fasta = FALSE)
Hello
x
[1] "T" "C" "C" "T" "G" "G"

The return() function explicitly specifies what value you want as the output. This is why R doesn’t only print "Hello" or "Goodbye" from the cat() (print) function.

We can finish making our optional FASTA format by adding a name for our random sequence.

generate_dna <- function(seqlength = 25, fasta = TRUE) {
    n <- sample(c("A", "T", "C", "G"), size = seqlength, replace = TRUE)
    
    if(fasta) {
      id <- paste (">len", seqlength, sep = "")
      n <- paste(n, collapse = "")
      cat(id, "\n", n)
    }
    return(n)
}
x <- generate_dna(6)
>len6 
 GCTACA

Amino Acid Sequence Generator

Q: Write a function called generate_protein() that makes random peptide sequences of a user-specified length in FASTA format.

aa <- c("A", "R", "N", "D", "C", "E", "Q", "G", "H", "I", "L", "K", "M", "F", "P", "S", "T", "W", "Y", "V")

generate_protein <- function(seqlength = 25, fasta = TRUE) {
  a <- sample(aa, size = seqlength, replace = TRUE)
  if(fasta) {
    id <- paste(">len", seqlength, sep = "")
    a <- paste(a, collapse = "")
    cat(id, "\n", a, "\n")
  }
  return(a)
}

x <- generate_protein()
>len25 
 QICFWKALKWLGGDDNVMWNTFCES
