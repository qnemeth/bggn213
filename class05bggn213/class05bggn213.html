Background

Today we are going to learn all about the ggplot2 package in R.

There are tons of graphics packages in R (over 250). These include “base R graphics” (like the plot() function we used last class) and add on packages like ggplot2.

Comparing Base Graphics With ggplot

First, we need some data to plot. We can use a built-in data frame (2D matrix) that comes with R: cars.

Experimenting with ggplot

Now, let’s try it with ggplot. First, we need to install the package using install.packages().

We don’t want to run install.packages("ggplot2") in the quarto document because then it will re-install the package every time we render the report.

Instead, we can type in the console.

You don’t always want to use all of your packages all of the time, just like you don’t need every book in a library at the same time. So, use the library() function to call up the package(s) that you need.

library("ggplot2")
ggplot(cars)

This just gives us a blank square, because ggplot needs more information.

Every ggplot needs at least 3 things:

  • The data: the data.frame we want to plot from
  • The aesthetics: how the columns of the data map to the plot
  • The geometry: how you want the plot to be drawn (points, lines, etc.)
ggplot(data = cars) + 
  aes(x = speed, y = dist) +
  geom_point()

Now we have a pretty basic plot. We can add different functions to improve it. There are hundreds of different geom functions that you can use to draw the plot differently. For example, let’s try to add a trend-line.

ggplot(data = cars) + 
  aes(x = speed, y = dist) +
  geom_point() +
  geom_smooth()
`geom_smooth()` using method = 'loess' and formula = 'y ~ x'

You can add additional arguments to geom_smooth to change the trend-line.

ggplot(data = cars) + 
  aes(x = speed, y = dist) +
  geom_point() +
  geom_smooth(method = "lm")
`geom_smooth()` using formula = 'y ~ x'

To change the appearance of the plot, you can add even more functions.

ggplot(data = cars) + 
  aes(x = speed, y = dist) +
  geom_point() +
  geom_smooth(method = "lm") + 
  theme_bw() +
  labs (x = "Speed (MPH", 
        y = "Stopping Distance (ft)",
        title = "Silly Plot of Stopping Distances")
`geom_smooth()` using formula = 'y ~ x'

We may have to do a bit more work to get basic plots at first, but ggplot actually saves time & effort in the long run.

Let’s try to color our scatterplot based on “State”. We can also add a custom set of colors for the different states.

ggplot(genes) +
  aes(x = Condition1, y = Condition2, col = State) +
  geom_point() +
  scale_colour_manual(values = c("mediumpurple", "deeppink4", "royalblue3"))

Now let’s add some labels.

geneplot <- ggplot(genes) +
  aes(x = Condition1, y = Condition2, col = State) +
  geom_point() +
  scale_colour_manual(values = c("mediumpurple", "hotpink2", "royalblue3")) +
  labs (x = "Control (no drug)", 
        y = "Drug treated",
        title = "Gene expression changes upon drug treatment",
        subtitle = "GLP1 inhibitor") +
  theme_bw()

Instead of typing out the same thing every time, you can assign the plot to an object, and then modify that object. For example:

myplot <- ggplot(cars) + 
  aes(x = speed, y = dist) +
  geom_point()
myplot + theme_bw()

We can also install additional packages to ‘mod’ ggplot. Let’s try combining four different plots into one figure with patchwork.

#install.packages("patchwork")
library(patchwork)

# Setup some example plots 
p1 <- ggplot(mtcars) + geom_point(aes(mpg, disp))
p2 <- ggplot(mtcars) + geom_boxplot(aes(gear, disp, group = gear))
p3 <- ggplot(mtcars) + geom_smooth(aes(disp, qsec))
p4 <- ggplot(mtcars) + geom_bar(aes(carb))

# Use patchwork to combine them here:
p5 <- (p1 | p2 | p3) /
      p4
p5
`geom_smooth()` using method = 'loess' and formula = 'y ~ x'

Back in base R, we can also use a function to separate our plot into multiple plots based on a particular column (State).

geneplot +
  facet_wrap(~State)

Let’s try to make a plot of life expectancy compared with GDP per capita.

le.gdp <- ggplot(gapminder) +
  aes(x = gdpPercap, y = lifeExp, col = continent) +
  geom_point(alpha = 0.1) +
  scale_colour_manual(values = c("hotpink2", "steelblue3", "darkturquoise", "mediumorchid1", "darkseagreen4")) +   
  facet_wrap(~continent)
le.gdp

The alpha value sets transparency level.

Now let’s try to make a histogram.

ggplot(gapminder) + aes(lifeExp, fill = continent) +
  geom_histogram()
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.
